# gui-st

Личная игровая библиотека для Windows: игры из разных лаунчеров в одном месте.

## Возможности
- Добавление игр: .exe, ярлык или ссылка лаунчера (`steam://rungameid/...`)
- Обложки (файл или ссылка), категории, избранное
- Учёт времени игры для запуска по .exe
- Поиск, сортировка, быстрый запуск
- Тёмная сине-фиолетовая тема, настройки

## Запуск из исходников
```
npm install
npm start
```

## Сборка .exe через GitHub
1. Создайте репозиторий и загрузите этот проект.
2. Вкладка **Actions → Build Windows EXE → Run workflow** — готовые файлы появятся в Artifacts.
3. Для релиза: `git tag v1.0.0 && git push origin v1.0.0` — установщик и portable-версия
   прикрепятся к странице **Releases**.

Данные библиотеки хранятся в `%APPDATA%/gui-st/library.json`.
